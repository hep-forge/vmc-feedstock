Feedstock for [vmc](https://github.com/vmc-project/vmc) — part of [hep-forge](https://anaconda.org/hep-forge).
Builds linux-amd64 + linux-arm64 in one matrix workflow and uploads to the
[hep-forge](https://anaconda.org/hep-forge) Anaconda channel.

Virtual Monte Carlo interface for ROOT

## Architectures

State per architecture: see the platforms badge above or [anaconda.org/hep-forge/vmc](https://anaconda.org/hep-forge/vmc).


## Install

```bash
conda install -c hep-forge -c conda-forge vmc
```
